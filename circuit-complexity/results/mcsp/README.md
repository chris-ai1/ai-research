# Boolean MCSP: research summary and literature check

Summary of a research session that ended on 22 November 2026, together with a literature-priority search run the same day. MCSP asks whether a truth table of N = 2ⁿ entries can be computed by a circuit with at most s gates. Below, T = s log₂ s.

**Status.** Every result here is an unrefereed, AI-written proof. The internal "referee" notes came from the same agent team. Three Lean files here, and one in the notes, formalize only small combinatorial lemmas. The manuscripts are in this directory; see [Files](#files). No result here is a breakthrough.

## Claimed results (written proofs, not independently checked)

Conventions throughout: N = 2ⁿ is the truth-table length and s the gate budget of the inner circuit. T = s log₂ s, and all logarithms are base 2. MCSP[s] accepts exactly the tables computable with at most s gates. ε, η, c denote fixed constants with 0 < c < 1. Asymptotics are as n → ∞. Implicit constants may depend on the fixed constants. "Full binary basis" (B₂) means arbitrary fan-in-two gates with unrestricted fanout and free negations.

| # | Model | Full statement | Manuscript |
| --- | --- | --- | --- |
| 1 | Deterministic B₂ circuits deciding MCSP | Every nonempty set A of N-bit strings that is closed under bitwise complement needs at least 2N − 2⌊log\|A\|⌋ − 1 gates to decide membership. Consequently exact MCSP[s] needs (2−o(1))N gates for every threshold 0 ≤ s = o(N/n). For n = o(s) and s = o(N/n), signed identifications give at least 2N − (0.456894 + o(1))s log₂ s gates. For n = o(s) below the Shannon scale, the smallest teaching set of the accepted class has (1+o(1)) s log s entries. A promise version with an additive gap between the two thresholds has the same leading bound. | [deterministic](papers/deterministic/main.pdf) · [signed identifications](papers/deterministic/signed-identifications.md) |
| 1b | Randomized B₂ circuits with small pointwise error | For each fixed ε > 0 and every integer threshold n − 2 ≤ s ≤ cN/n (for an absolute c > 0), any distribution over circuits that decides exact MCSP[s] with error at most N^(−1−ε) on every input has size at least 2N − O(N/n). | [probabilistic](papers/probabilistic/main.pdf) |
| 1d | Randomized B₂ circuits with perfect soundness | If every hard table is always rejected and each easy table is accepted with probability greater than 1/2, exact MCSP[s] needs at least 2N − 2⌊log₂\|Aₛ\|⌋ − 1 gates, where Aₛ is the family of easy tables. This gives (2−o(1))N for every 0 ≤ s = o(N/n). | [one-sided teaching bound](papers/probabilistic/one-sided-teaching.md) |
| 1e | Deterministic and randomized B₂ circuits at thresholds n−1 and n | For s ∈ {n−1, n} and n ≥ 5, exact MCSP[s] needs at least 2N − N/(1 + n + n(n−1)/2) − 2 gates, which is 2N − O(N/n²). The same bound holds for randomized circuits with pointwise error below 1/(cN²n⁴), for an absolute c. Computer-assisted: the proof relies on exhaustive tables of 4- and 5-variable functions. The note also shows 2N − 2 for n = 4 at 3 ≤ s ≤ 6 and n = 5 at s ∈ {5, 6}, and, conditional on an unproven conjecture, for 2n−5 ≤ s ≤ 2n−2. | [pair certificates](papers/probabilistic/pair-certificates.md) |
| 2a | Approximate degree and quantum queries | For fixed ε, η > 0, uniformly in (2+η)n ≤ s ≤ (1−ε)N/n: the 1/3-approximate degree and the bounded-error quantum query complexity of MCSP[s] are both Θ(√(NT/(1+log(N/T)))). For error δ ∈ (0, 1/3] both are Θ(min{N, √(N(K + log(1/δ)))}), where K = T/(1+log(N/T)). The upper bound follows from Kothari's oracle identification. | [degree](papers/degree/main.pdf), [queries](papers/queries/main.pdf) |
| 2b | Quantum queries at very small budgets | For s ≤ n − log n − 2 log log(n+2), the bounded-error quantum query complexity is Θ(√N). For circuits over AND/OR/NOT with every NOT counted and unrestricted fanout, it is Θ(√N) for all 0 ≤ s ≤ (1+c)n, for an absolute constant c > 0, on the whole input cube. | [queries](papers/queries/main.pdf), [low-budget](papers/low-budget/main.pdf) |
| 2c | Randomized B₂ circuits at small thresholds | For fixed 0 < γ < 1 and 0 ≤ s ≤ (1−γ)n/log₂ n, accepting easy tables with probability at least p and hard tables with probability at most e costs (1−e/p+o(1))N gates for fixed 0 < e < p ≤ 1. At ordinary pointwise error 1/3 the optimal size is (1/2+o(1))N. | [randomized gate size](papers/low-budget/randomized-circuits.md) |
| 3 | Gap MCSP with polynomially separated thresholds | Promise: the circuit size is at most s = Θ(N^a) or greater than t = Θ(N^b), with fixed 0 < a < b < 1. Bounded-error randomized query complexity is Θ(Ns/t) and quantum query complexity is Θ(s√(N/t)), and both upper bounds have perfect completeness. Threshold degree, globally bounded rational approximate degree and bounded-error postselected quantum query complexity are all Θ(s). | [gap](papers/gap/main.pdf) |
| 4a | Read-k branching programs and DNNF | For every fixed k and (1+ε)n ≤ s ≤ (1−ε)N/n, the following all need, and can achieve, size 2^Θ(s log s) for MCSP[s]: bounded-error randomized syntactic read-k branching programs, nondeterministic ones of either polarity, and decomposable negation normal forms for MCSP or its complement. The proof builds distributions on the two sides of MCSP whose probabilities differ by at most exp(−Ω(N)) on every balanced rectangle. | [branching](papers/branching/branching.pdf) |
| 4b | One-tape Turing machines with one-way input | At s = cN/n, a randomized machine with one two-way work tape and a one-way input tape needs expected time Ω(N²) on a distribution of inputs, even with any fixed number of input-head reversals. For n + ω(1) ≤ s ≤ (1−ε)N/n, padding gives Ω(((s−n) log(s−n))²). | [tape](papers/tape/main.pdf) |
| 4c | One work tape with a two-way input head | When the threshold is part of the instance, either MCSP or its complement needs time Ω(N log N) on accepted inputs, for machines with perfect soundness. This covers the shortest nondeterministic accepting paths and the expected time of one-sided randomized machines. For almost every fixed density below the Shannon bound, the prescribed threshold is hard at all large lengths. | [twoway](papers/twoway/twoway.pdf) |
| 5a | Parity decision trees at dense budgets | At s = ⌊cN/n⌋, the worst-case number of adaptive parity queries needed to decide MCSP[s] with constant error is (c+o(1))N. The base-two logarithm of the smallest bounded-error parity decision tree is also (c+o(1))N. | [dense-circuits](papers/dense-circuits/main.pdf) |
| 5b | Bounded-error B₂ circuits at dense budgets | Combined with Chen–Kabanets' simulation of circuits by parity decision trees, 5a gives (2.5−o(1))N gates for bounded-error B₂ circuits deciding MCSP when the threshold is part of the input. | [dense-circuits](papers/dense-circuits/main.pdf) |
| 5c | Full B₂ circuits at fixed dense thresholds | At s = ⌊0.99435 N/n⌋, deterministic MCSP[s] needs more than 2.52286N gates, and pointwise two-sided error at most 2^(−0.00564N) needs more than 2.52281N gates. The gap from 0.993N/n to 0.99435N/n needs more than 2.51775N deterministic gates. At s = ⌊0.99365 N/n⌋ the deterministic bound exceeds 2.52293N. The optimized inequality has limiting coefficient 2.52293396 to eight decimal places. | [tilted](papers/tilted/main.pdf), [optimization](papers/tilted/optimum.md) |
| 5d | Parity constraints and affine subspaces | Take r consistent parity constraints on the table. In the worst case a solution needs (r+o(N))/n gates when r = Θ(N), and (1+o(1)) r/log r gates when n log n (log log n)^K ≤ r ≤ N, for an absolute K. At s = cN/n the largest affine subspaces made entirely of accepted tables, or entirely of rejected tables, have dimensions (c+o(1))N and (1−c+o(1))N respectively. | [affine](papers/affine/main.pdf) |
| 6a | Sign-rank and unbounded-error communication | At s = cN/n, the MCSP communication matrix has sign-rank 2^Ω(N) for every fixed balanced partition of the entries. So private-coin protocols with any positive advantage need Ω(N) bits. After an invertible linear change of coordinates, every basis is hard when both views have rank below the inner information rate. When one view has rank above that rate, most bases have constant unbounded-error complexity. | [sign-rank](papers/sign-rank/main.pdf) |
| 6b | Bounded-error communication | At s = (c+o(1))N/n and any fixed split of the entries with proportions α and 1−α, randomized protocols with error 1/3 need Ω(N) bits, even with public coins and arbitrary interaction. So the trivial protocol is optimal up to a constant factor. | [communication](communication.md) |
| 6c | Parity bias and XOR-share communication | If log s/log n → ∞ and s log s ≤ (1−η)N, then the best bias against every nonempty parity achievable by a distribution supported on MCSP[s] satisfies −log(bias) = (1/2+o(1))T. When the table is the XOR of two parties' strings, randomized communication is (1+o(1))T bits and entanglement-assisted quantum communication is (1/2+o(1))T qubits. | [gap](papers/gap/main.pdf) |
| 7 | Circuits satisfying few parity constraints | Every consistent system of r parity constraints on the 2ⁿ entries has a solution with n + 2^O(r) gates. For r → ∞ with r ≤ c log n, some systems need n + 2^Ω(r) gates, using parities on coordinate faces. Also, every distribution on functions of at most (1+c)n gates has some parity of truth-table entries with bias at least 1 − 2^(−Ω(n)). | [parity-excess](papers/parity-excess/main.pdf) |
| 8b | Prescribed cell quotas and marginals | Partition the entries into cells with prescribed numbers of ones, and let a 2^(−R) fraction of tables of the right total weight meet the quotas. Then every placement of the cells admits a satisfying table with R/n + O(N log n/n²) gates, and a uniform random permutation of the cells makes this leading-order tight when R = Θ(N). For a distribution of circuits with prescribed probability p_i at each address, the typical per-circuit budget is (N H(p̄) − Σ H(p_i))/n + O(N log n/n²). This extends to arbitrary joint laws on disjoint cells of size o(N). | [witnesses](papers/witnesses/main.pdf) |
| 9 | Randomized B₂ circuits at small thresholds | For every 0 ≤ s ≤ n−3, pointwise two-sided error o(1/N) requires at least (3/2−o(1))N gates for exact MCSP[s]. Error 1/N requires at least (9/8−o(1))N gates. | [Two-bit changes and circuit wiring](papers/probabilistic/two-flip-wiring.md) |

An extension of row 5c places parity pivots in one part of a truth-table address partition. At s = ⌊0.99325 N/n⌋ it gives more than **2.52437N gates** for unrestricted deterministic B₂ circuits and for pointwise error at most 2^(−0.0074N). At s = ⌊0.99365 N/n⌋ it gives 2.52435N. At the original exact threshold it gives 2.52419N deterministically and 2.52323N at the original error exponent 0.00564. The original gap gives 2.51941N deterministic gates. [Address partition and proof](papers/tilted/address-split.md) · [One-pivot repair](papers/tilted/private-pairs.md)

**Still open:** query bounds in the window between (1+c)n and (2+η)n gates, approximate degree for gap MCSP, and the circuit lower bound that hardness magnification would need.

## How each result compares with the literature

These verdicts come from targeted searches, mostly of abstracts, so they are preliminary.

- **#1 is the strongest result.** Chen–Li–Yang (CCC 2022, [ECCC TR22-086](https://eccc.weizmann.ac.il/report/2022/086/)) explicitly leave "an unconditional 2n−o(n) circuit size lower bound for MCSP, even against deterministic circuits" open. No later paper proves it. It is a short, clean answer to a published open question, suitable for a conference such as CCC, STACS or ICALP. Wittcop's earlier manuscript at s = n−1 must be credited; the draft does.
- **#1b is new but not a breakthrough.** Hardness magnification needs more than 2N + O(N/log log N) gates. This bound reaches 2N − O(N/n), so it stops just short and has no consequence for P versus NP.
- **#1e narrows the deficit of #1b at two thresholds.** At s ∈ {n−1, n} the shortfall from 2N drops from O(N/n) to O(N/n²). The note reads Chen–Li–Yang's Theorem 4.3 as putting the magnification threshold at 2N + O(N·s log s/log² N) with error exp(−Ω(s log s)), which would make the remaining gap at s = n an additive O(N log n/n) and would replace the 2N + O(N/log log N) figure in the previous item. That reading comes from extracted PDF text and has to be checked against the paper.
- **#2 looks new.** The upper bound follows from Kothari's oracle-identification theorem ([arXiv:1311.7685](https://arxiv.org/abs/1311.7685)), and the draft should say so plainly. No matching lower bound for the MCSP decision problem was found.
- **#3 looks new.** The nearest work (Oliveira–Pich–Santhanam, Allender–Ilango) proves no query bounds of this kind.
- **#4 extends known work.** It sharpens Cheraghchi–Hirahara–Myrisiotis–Yoshida ([STACS 2021](https://eccc.weizmann.ac.il/report/2020/103/)), who proved an N^1.99 bound against randomized one-tape machines. It generalizes Glinskih–Riazanov (LATIN 2022) from read-once programs at linear s. Both are cited.
- **#5 overlaps with prior work.** Hoza–Lv ([RANDOM 2025](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.APPROX/RANDOM.2025.35)) nearly imply a one-sided 2.49N bound without mentioning MCSP. The dense manuscript cites them; the tilted one does not and should. No manuscript cites Mishra–Santhanam ([ECCC TR26-260](https://eccc.weizmann.ac.il/report/2026/260/), revised 3 Nov 2026), who prove 4n−O(log n) for an explicit function in P, now the record for explicit lower bounds. It does not cover MCSP, but the drafts' comparisons should mention it. The 2.5226N constant is a modest result.
- **#6 and #7 look new.** For #6, the method is the Cheraghchi–Kabanets–Lu–Myrisiotis local-generator framework; the sharp constants and the sign-rank result appear new. For #7, a standard small-bias construction may beat 2^O(r) when r is much larger than log n, which the paper should discuss.
- **#8 is the weakest.** The counting results are natural sharpenings of Pippenger (1977) and Andreev–Clementi–Rolim, which the drafts cite. The zeros result is a new application of Szegő's classical theorem. Both could only be minor papers.

## RH and ETH

- **RH:** the [Lean community post](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/) (21 Nov 2026) exists and certifies a formal proof by Levent Alpöge.
- **ETH:** the October ["ETH is False" preprint](https://github.com/openai/math) exists, with a review group led by Impagliazzo, Paturi and Williams. [Strassle–Subercaseaux](https://arxiv.org/abs/2611.11832) carry it over to nondeterministic Turing machines.

Neither helps with MCSP beyond one small application, to minimum DNF under restrictions.
