\paragraph{A generator against adaptive testers.}
Fix $k$ and any $c$ strictly between $1-\beta_k$ and one. For a constant $\gamma>0$, the uniform-reference construction gives a polynomial-time map from at most $cN$ independent random bits to $N$ output bits. Every output truth table has circuit size at most $cN/n$. Every deterministic syntactic read-$k$ program of size at most $2^{\gamma N}$ has acceptance probability within $2^{-\gamma N}$ of uniform. The support intersects every accepting set of a nondeterministic program of that size having uniform measure above $2^{-\gamma N}$. Indeed for deterministic programs sum the rectangle errors over the disjoint traces. For a nondeterministic program missing the support, each trace has uniform measure at most the rectangle error; sum over the cover.

To count the seed, set $t=1$. A uniformly selected word of the sum code is the sum of independent uniform summands. The seed length divided by $N$ is at most
\[
 r+1/b+\log(K)/b+L/(2B_0)+2\rho+(\log B+1)/B+o(1).
\]
This fits below $c$ with the preceding parameter choices. Generating the output in time polynomial in $N$ requires making the two growing binary code factors effective. For either requested length $a$, put $v=\lceil\log_2 a\rceil$, $\ell=\lceil v/(1-\rho/4)\rceil$, and $j=\lfloor a/\ell\rfloor$. A Reed--Solomon code of length $j$ over $\mathbb F_{2^v}$ and dimension $\lfloor(1-\rho/4)j\rfloor$ has relative distance at least $\rho/4$. Encode each symbol using a binary linear inner code of length $\ell$, dimension $v$, and relative distance a small constant $\theta_\rho>0$. Greedily choose a new basis vector outside Hamming balls of radius $\lceil\theta_\rho\ell\rceil-1$ around the current span. A constant with binary entropy below $\rho/8$ suffices for large lengths. Both the candidate set and the span can be enumerated in polynomial time in $a$, as can the field elements and an irreducible polynomial. Append fewer than $\ell$ zeros to reach length $a$. The concatenated code has rate greater than $1-\rho$ and positive constant relative distance; Gaussian elimination constructs the required check matrix, padding redundant rows if needed. The remaining finite menu can be found by exhaustive search once for fixed $k,c$.

Bogdanov, Papakonstantinou and Wan, FOCS 2011, Lemma~2 and the remark immediately following its proof explicitly give a generator against arbitrary possibly intersecting factors on sets of size at most $(1-\beta)N$, using $(1-\rho_\beta)N$ seed bits. Their Fourier proof uses a binary code plus small-bias noise. The preceding read-$k$ decomposition applied to that result already gives the qualitative constant-stretch generator and hitting set, with exponentially small error. The added conclusions here are the output-table circuit bound and the ability to choose every fixed seed rate $c>1-\beta$. Indeed, for any seed rate $c<1-\beta$, testing membership in the projected support on $(1-\beta)N$ visible bits distinguishes with advantage $1-2^{-\Omega(N)}$. The construction thus attains the limiting rate. Following their Lemma~2 the authors ask how closely one can match the bounds $N/2+O(\log(1/\epsilon))$ for a known cut at an unknown cut. Our limiting rate does not establish their additive error dependence.

Their RANDOM 2012 Theorems 1--2 treat linear-length programs with large-alphabet nonoblivious access and binary oblivious access, respectively. Cheraghchi et al., STACS 2021, Theorem 6 gives a local hitting set for read-once nondeterministic programs; for polynomial size its seed has length $\widetilde O(\sqrt N)$. Corollary 7 deduces a co-nondeterministic MCSP bound. Their Section 2.6 calls a generator local when each fixed-seed truth table has circuit complexity at most the seed length. This is satisfied after padding the seed to $\lfloor cN\rfloor$. The constant-rate code and noise in Bogdanov et al.\ do not by themselves supply the sharp $cN/n$ bound on every output truth table; arbitrary dense fixed-seed linear combinations must also be cheaply computable on a coordinate address.
