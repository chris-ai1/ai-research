# Interactive communication for Boolean MCSP

Let N=2ⁿ, and let MCSP accept a truth table if its Boolean AND/OR/NOT circuit size is at most s. Alice receives the entries at a set P of ⌊αN⌋ addresses; Bob receives the remaining entries. They know the partition and may compute arbitrarily between messages. Here α is any fixed number strictly between zero and one. Fix constants 0<c<1 and s=(c+o(1))N/n.

**Theorem under review.** Every randomized protocol deciding Boolean MCSP with worst-case error at most 1/3 sends Ω(N) bits in the worst case, uniformly over the choice of partition. This holds with public randomness and arbitrary interaction. The trivial protocol sending one party's input is optimal up to constant factors. There is also a linear lower bound for quantum communication with prior entanglement, subject to the standard generalized discrepancy theorem specified below.

## The two input distributions

Choose real constants t,r with c<t<1 and max(α,1−α)<r<c/t. Taking t sufficiently close to c makes this possible. We can and do take t dyadic. An efficiently specified collection of about tN coordinates is active. All inactive coordinates are zero. We construct a binary linear space G on the active coordinates with three properties.

1. Its projections onto Alice's and Bob's active coordinates are both surjective.
2. Every nonzero dual word has weight at least δN, for a constant δ>0.
3. Each table in G has a circuit using at most (c−ε)N/n gates, for some ε>0.

For the hard reference take the uniform distribution μ on the active coordinates. The number of easy tables is at most 2^((c+o(1))N) by rooted circuit counting. Since there are tN−o(N) active coordinates, the probability under μ of an easy table is exponentially small.

For the easy distribution ν, start with a uniform word of G and add sparse independent noise as follows. Partition the whole table into address blocks of B sites for a fixed power of two B. Independently in each block select a uniform site and an independent fair bit, and put that bit at the site and zero elsewhere. Set all inactive bits to zero. A fixed noise table is computed by log₂ B+1 arbitrary lookups on n−log₂ B bits, comparing the within-block address with the retrieved site, and using the retrieved bit. By Lupanov's bound the lookups use ((log₂ B+1)/B+o(1))N/n gates. A separate inexpensive mask is included below. Choose B large enough to fit the ε margin. XOR with the sampled word of G in constant additional gates. Thus every sample of ν is easy. For any binary character of weight w on the active sites, extended by zeros elsewhere, the absolute bias of the noise is

    ∏ over blocks j of (1−w_j/B) ≤ exp(−w/B),

where w_j is the character's weight in block j. This formula uses the fair bit to annihilate the character whenever the sampled site lies in its support.

## Building the space G

First build a block code G₀. Let b be a power of two between √n and 2√n. After an invertible affine transformation of the address bits, use the first t fraction of the consecutive b-site blocks. A uniformly random affine transform is transitive on ordered pairs of distinct addresses. In any block, Alice's number of sites has mean αb+o(1) and variance O(b). Thus there is a transform in which all but o(N/b) blocks contain αb+o(b) Alice sites and (1−α)b+o(b) Bob sites. For instance use tolerance b^(3/4). Fix the transform. Set h=⌊(1−r)b⌋ and take a common random h-by-b binary parity-check matrix. On each balanced block, both submatrices restricted to Alice and to Bob have full row rank except with probability 2^(−Ω(b)), by a union bound on nonzero row combinations. Choose one matrix losing only o(N/b) of the active blocks. The remaining blocks, with all of their sites, constitute the active domain U. Its size is (t+o(1))N. Use its common kernel independently in each block, and use zero elsewhere. This defines G₀. Since constraints in each block can be solved using either party's positions alone, G₀ projects surjectively onto each party's active coordinates.

There are b−h independent message bits per block. Hardwire them as b−h lookup functions of the block address, with zero messages in discarded blocks. To get the leading constant t when t<1, express the active prefix as a fixed finite disjoint union of dyadic address intervals. For each interval the functions use n−log₂ b−O(1) address bits. The sum of their domain lengths across intervals is tN/b. Lupanov synthesis and the O(b²) shared generator and index selection give (tr+o(1))N/n gates. Affine reindexing costs O(n²). The activity mask for U is one arbitrary lookup on n−log₂ b bits after the same transform, using o(N/n) gates.

Next use the easy limited-independence space V from [the product-code construction](product-code.md). For any sufficiently small ρ>0 every word costs at most (9ρ+o(1))N/n gates, and each nonzero parity vanishing on V has weight at least δN for some δ=δ(ρ)>0. Restrict V to U and mask all other coordinates. The dual of the restricted space has the same minimum distance lower bound: a parity on U vanishing there extends by zeros to a parity vanishing on V. Let G=G₀+V|_U, extending by zero off U. It retains both surjectivities, and its dual is a subspace of the dual of V|_U. Take ρ small enough that tr+9ρ<c. The XOR and masks fit in the remaining gates. These steps prove the three required properties.

## Why interaction cannot distinguish the distributions cheaply

For characters ξ on Alice's active bits and η on Bob's, the mean of χ_ξχ_η under a uniform word of G equals one if (ξ,η) is in G⊥ and zero otherwise. Surjectivity onto each side forbids a nonzero dual word supported on only the other side. Thus for any given ξ there is at most one matching η, and conversely. This partial matching is essential: small parity biases by themselves need not fool rectangles. Adding independent noise to the code multiplies each nonconstant matched coefficient by a number of absolute value ≤exp(−δN/B). Under μ all nonconstant coefficients vanish.

For any rectangle A×D on the active inputs, expand 1_A and 1_D in the orthonormal Boolean character bases for the uniform marginal measures. The constant term agrees. Cauchy–Schwarz along the partial matching and Parseval give

    |ν(A×D)−μ(A×D)| ≤ exp(−δN/B) √(μ_A(A)μ_B(D)).

A deterministic protocol of cost q accepts on a disjoint union of at most 2^(q+1) rectangles. Averaging over public or private random coins preserves the upper bound 2^(q+1)exp(−δN/B) on the difference of acceptance probabilities. Success with error 1/3 forces a difference of at least 1/3−o(1), proving q=Ω(N).

For quantum communication, form the signed matrix K=(ν−μ)/2 on active strings and code the Boolean answer as +1 for easy and −1 for hard. Its entrywise 1-norm is at most one and its correlation with the sign matrix is 1−o(1). Under the normalized Walsh transforms on both sides, K has the matching coefficients above divided by 2√(XY), where X and Y denote the row and column domain sizes. Its operator norm is therefore at most exp(−δN/B)/(2√(XY)). The generalized discrepancy lower bound gives linear communication, even with prior entanglement. Alternatively a uniform constant-entrywise-error approximation of the sign matrix must have rank exp(Ω(N)): its inner product with K is bounded above by the operator norm of K times its trace norm, and Frobenius norm by O(√(XY)).

## Prior work and scope

The proof combines erasure coding, the dual of a tensor-product code, Lupanov synthesis, and Fourier mixing of a code distribution with structured sparse noise. It concerns the communication needed to *decide* size-bounded membership when parties hold parts of a truth table. Size bounds for restricted branching programs and communication-based lower bounds for circuits containing low-communication gates address related resources. Comparisons with the existing literature and independent audit are in progress. [Cheraghchi et al. on branching programs for MCSP](https://doi.org/10.4230/LIPIcs.STACS.2021.23) · [Kabanets et al. on low-communication gates](https://www.cs.sfu.ca/~kabanets/Research/low-comm-gates.html)

## Reduction to smaller gate budgets

The proof also separates two fixed dense size thresholds γ₁M/m and γ₂M/m, for γ₁<γ₂ sufficiently close in any prescribed compact subinterval of (0,1). Choose the active density t>γ₂ and design the codes and noise below γ₁ by keeping t·max(α,1−α)<γ₁. This separation is stable for all cut fractions in a sufficiently small closed neighborhood of the original α. The uniform hard law is exponentially far in probability from complexity at most γ₂M/m.

Suppose n=o(s) and s≤(1−ε)N/n. As in [the threshold-degree proof](threshold-degree.md), choose m≤n with M=2^m=Θ(s log₂s) and sm/M bounded above and below by constants in (0,1). For the dense end where m=n the result was proved directly. On the m-bit cube choose a random affine graph A={(y,Ly+b)}, writing an n-bit address as (y,z) with |y|=m. The graph selects one address from each fixed y fiber. The two selected suffix values for distinct y are independent uniform bit vectors. Therefore the expected number in P is |P|M/N and the variance at most M/4. Some graph induces cut proportion α+o(1) in the smaller cube. The known constants for the preceding dense proof may be chosen uniformly for this cut and the compact range of sm/M. Choose inner yes/no budgets separated by a sufficiently small fixed fraction on opposite sides of s.

Embed an m-variable table f into the n-variable table F(y,z)=f(y)·1[z=Ly+b]. On the graph the two parties see exactly their induced parts of f, and the off-graph inputs are known zeros. The characteristic test and the substitution z=Ly+b each cost O(n⌈m/log₂ n⌉+n) gates. For the computation split y into batches of at most (log₂ n)/2 inputs, precompute every parity of each batch in O(√n) gates per batch, and assemble each output linear form with one parity per batch. When s grows at most polynomially in n this cost is O(n)=o(s), since m=O(log s). When s grows faster, the elementary O(n²) bound suffices; one can split uniformly at s=n³. A circuit for f yields one for F by the guard, while a circuit for F yields one for f by substitution. Thus the fixed dense gap in f makes the outer labels correct at s. The same reduction preserves the communication lower bound, including its generalized discrepancy witness on the restricted communication submatrix.

### Removing the overhead near the addressing threshold

A coordinate face gives the stronger range s≥(1+η)n for every fixed positive η. If a subset of an n-cube has density α bounded away from 0 and 1, then some m-dimensional coordinate face has density in [δ,1−δ] for δ=min(α,1−α,1/4)/2 and every 1≤m≤n. Fix any m free coordinates. If no face already works, there must be both low- and high-density parallel faces because their average is α. The graph of their fixed addresses is connected. Pick adjacent low and high faces and free the differing fixed bit in place of one of the original free bits. Fix the latter arbitrarily. At most δ·2ᵐ unwanted points come from each old face, so the new face has density between 1/2−δ and 1/2+δ.

Write q=n−m. Embed a nonconstant m-variable function f on that face by adjoining the conjunction of the q prescribed literals, and extending by zero outside. For q≥1 the padded function F has minimum AND/OR/NOT circuit size between C(f)+q and C(f)+q+1. For the upper bound group the positive literals into a conjunction and the negative literals into the negation of a disjunction, then combine them with f. For the lower bound, successively fix each guard bit to its prescribed value. It is essential before it is fixed because f is nonconstant. A first gate reading it can therefore be deleted after substitution. Gates using its value several times cause no difficulty, and propagating constants in this basis introduces no new gates. For the easy law the upper bound suffices even on a constant f. For the hard law every function in its support is nonconstant.

Choose m≤n so M=2ᵐ has order s log s and (s−n+m)m/M belongs to a fixed compact subinterval of (0,1). This is possible by taking the first m for which (s−n+m)m/2ᵐ falls below 1−ε/2, on the decreasing branch; m=n already satisfies it. The ratio between consecutive values is bounded below by 1/2. Since s−n≥ηs/(1+η), the stated size of M follows. The dense theorem on this face with a fixed small gap around s−q and a uniformly balanced induced split gives Ω(M)=Ω(s log s). One unit of synthesis slack fits into that fixed gap. This face argument also proves the range covered by the affine argument above and is shorter.

The upper bound uses the rooted count of easy tables. Alice checks which prefixes of easy tables match her data. If none do she sends a flag. Otherwise she sends the identifier of her entire observed prefix in the fixed list of distinct prefixes of easy tables, after which Bob decides exactly. For n=o(s), this requires O(s log₂ s) bits. Thus for every fixed partition fraction bounded away from zero and one, throughout this range both interactive bounded-error randomized and prior-entanglement quantum communication have order s log₂ s. A matching deterministic upper bound applies as well. [Generalized discrepancy and entangled quantum communication](https://doi.org/10.1002/rsa.20232)

## A different behavior below the addressing cost

When 2^(n−s)≫s log₂(n+s), a uniformly random balanced partition has a constant-bit public-coin communication protocol with probability tending to one. If two different easy tables f,g are viewed as real functions of their n address variables, f−g is nonzero and has degree at most s+1 because each circuit depends on at most s+1 raw variables. A nonzero degree-d multilinear polynomial is nonzero at at least 2^(n−d) Boolean assignments. The distance of such a pair is therefore at least 2^(n−s−1). The probability that either side of a random fixed-fraction cut misses its disagreements is exp(−Ω_α(2^(n−s))). Taking a union bound over at most 2^(O(s log(n+s))) pairs shows that, with high probability, each local view separately identifies at most one easy table. Each party can compute its unique candidate, if any. They exchange failure flags and run a public-coin equality fingerprint on the candidates. In particular the all-orders Ω(s log s) characterization in the superlinear regime cannot extend unchanged to s≤n−2log₂n. This argument gives a communication upper bound for typical partitions and measures no local computation time.

## All-partition upper bound without dependence on the address dimension

For every partition and every s≥1 there is a public-coin bounded-error protocol using O(s log₂(s+2)) bits. Let r=s+1. Hash the n raw input variables uniformly into m=100r² groups. Use a prime field of order q between 100m and 200m. For each group b consider the linear form

    D_b = Σ_x R_x [f(x)−f(x with all coordinates of group b set to zero)],

with independent uniform public coefficients in the field. The difference vector is identically zero exactly when the group contains no relevant variable. Indeed, invariance under the projection onto the all-zero face implies invariance under every change within the group. For a relevant group D_b vanishes with probability 1/q. Alice and Bob can compute additive shares of all D_b because the forms are linear in the input entries, even when a projected address belongs to the other party.

Alice sends her shares of the 2r moments Σ_b b^j D_b for 0≤j<2r, and one further random linear checksum of D with fresh public coefficients. Bob adds his own contributions. The moments identify at most one candidate with support of size at most r: any two would give a nonzero kernel vector on at most 2r distinct columns of a Vandermonde matrix. Bob rejects if there is no candidate or the checksum disagrees. If f depends on more than r variables, a fixed r+1 of them land in distinct groups except with probability at most binom(r+1,2)/m. On that event all these groups have nonzero values except with probability (r+1)/q, and any incorrect sparse candidate survives the independent checksum with probability 1/q. Thus this step rejects a function with too many relevant variables with probability greater than 0.9.

Otherwise with probability at least 0.99 the hash is injective on all relevant variables. Form the induced m-variable function f_h(z)=f(z_{h(1)},…,z_{h(n)}). This preserves circuit size when the hash is injective on the relevant variables: variable identification yields one inequality; ignoring extraneous coordinates and renaming the relevant inputs yields the other. Alice and Bob can each read their local part of the induced table, since the address map and original split are public. They now use the deterministic prefix-identifier protocol on m=O(s²) raw inputs, whose length is O(s log₂(s+2)). All field elements earlier in the protocol use O(log(s+2)) bits each. If the local split for the induced table is degenerate, the same protocol applies.

For the standard split according to the first address bit, the communication lower bound Ω(s log(s+2)) holds for every growing s below the stated fraction of the Shannon threshold. Embed an m-input table with its first coordinate preserved by ignoring n−m raw inputs; the cut is preserved and minimum circuit size is exactly invariant. Thus both the optimal universal upper bound and the dependence on which partition is chosen at low thresholds are sharp. For a second explicit cut on which communication is constant, split by the parity of the raw address when 2(s+1)<n. Any two easy functions together omit at least one variable. Every disagreement can be extended to points on either side by flipping that variable. Hence each side identifies at most one easy candidate and public-coin equality suffices.

The same construction is a one-pass randomized sketch in any predetermined read order, using O(s log₂(s+2)) state bits with public randomness and unrestricted computation. Accumulate the Vandermonde syndromes and checksum linearly. In parallel, accumulate a public random linear fingerprint of the induced table f_h of length O(s log(s+2)) bits. Its length exceeds log₂ of the number of size-s tables on m=O(s²) variables by a constant, so checking for a match against the entire family has false-positive probability at most 0.01 and accepts every easy induced table. Each induced entry is determined by one original entry, and its contribution is known when that original entry arrives. The final decision combines this check with the relevance sketch. For an explicit randomized branching-program size bound one can restrict to O(N) complete public random tapes by a Chernoff bound and a union bound over the 2^N inputs. The resulting randomized ordered read-once program has size at most poly(N)·2^(O(s log₂(s+2))).
