# How many integer roots can a short arithmetic program have?

[Read the paper (PDF)](paper.pdf) · [LaTeX source](paper.tex)

The Shub–Smale conjecture asks whether the number of distinct integer roots of a nonzero polynomial is bounded by a polynomial in the number of gates needed to compute it from 1 and the variable. This note explains the known nearly quadratic construction and derives an exponential upper bound that accounts for the order of additions and multiplications.
